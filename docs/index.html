# Über mich

Angefangen hat alles schon in der Schulzeit: Webseiten in PHP bauen, Sachen auseinandernehmen und alles ausprobieren, was sich irgendwie programmieren ließ. 2011 wurde daraus mit der Ausbildung zum Fachinformatiker für Anwendungsentwicklung ein Beruf. Seit 2014 bin ich bei Enghouse Networks in der Entwicklung und arbeite dort als Fullstack-Entwickler, vom Java-Backend bis zur React-Oberfläche.

KI-Werkzeuge gehören für mich fest zum Alltag, als Pair-Programmer, Reviewer und Sparringspartner. Die Verantwortung fürs Ergebnis bleibt bei mir. Diese Seite ist übrigens auch zusammen mit Claude Code entstanden.

Privat landet so gut wie jedes Problem irgendwann in einem kleinen Projekt. Manchmal ist das ein Pull Request für ein Open-Source-Tool, das ich selbst benutze, und manchmal eine App, die seit über zehn Jahren im App Store steht.
