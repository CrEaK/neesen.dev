# About

It all started back in school: building websites in PHP, taking things apart and trying everything that could somehow be programmed. In 2011 an apprenticeship as an application developer turned that into a job. Since 2014 I've been in R&D at Enghouse Networks, working full-stack from the Java backend to the React frontend.

AI tools are part of my everyday work, as pair programmer, reviewer and sparring partner. The responsibility for the result stays with me. By the way, this site was built together with Claude Code, too.

In my spare time, pretty much every problem ends up as a small project. Sometimes that's a pull request for an open source tool I use myself, sometimes an app that has been on the App Store for more than ten years.
